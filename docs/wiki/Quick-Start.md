# Quick Start

Этот раздел описывает практичный старт в survival без Creative.

## Первые цели

1. Собери basic материалы: planks, glass, glass panes, copper ingots, iron ingots, iron nuggets, redstone.
2. Найди или купи у villagers растения: cannabis, tobacco, coca, coffea, hops, morning glory, belladonna, jimsonweed, peyote, agave, grapes.
3. Сделай Drying Table.
4. Высуши первые листья и buds.
5. Сделай Mash Tub, если хочешь идти в напитки и алкоголь.
6. Сделай Bunsen Burner и Tray, если хочешь идти в химическую линию.

## Базовые рецепты станций

```text
###
#R#

R = redstone
```

## Ранние цепочки

Cannabis/tobacco:

- Cannabis buds -> Drying Table -> Dried Cannabis Buds.
- Cannabis leaf -> Drying Table -> Dried Cannabis Leaf.
- Tobacco leaves -> Drying Table -> Dried Tobacco.
- Dried Tobacco + paper -> Cigarette/Cigar.
- Dried Cannabis Buds + paper -> Joint.

Coffee/coca:

- Coffea cherries -> smelting -> Coffee Beans.
- Coffee Beans + water-filled hot drink receptacle -> Coffee.
- Coca leaves -> Drying Table -> Dried Coca Leaves.
- Dried Coca Leaves -> Cocaine Powder.

Alcohol:

- Fill Mash Tub with water.
- Add fruit/grain ingredients.
- Let it ferment.
- Use Barrel for maturation.
- Use Distillery + Flask for distillation.

Chemistry:

- Put Bottle on Bunsen Burner.
- Fill Bottle with water.
- Add a supported ingredient.
- Heat burner.
- Route output through Glass Tube into Flask or Tray.
