# Alcohol Fermentation and Distillation

Алкогольная система строится вокруг Mash Tub, Barrel, Distillery и Flask.

## Основная цепочка

1. Залей water в Mash Tub.
2. Добавь mashing ingredients.
3. Дождись fermentation.
4. Перелей жидкость в Barrel для maturation или в Distillery для distillation.
5. Разлей результат в drink holders.

## Mashing Recipes

Большинство простых mash recipes используют water и 8 одинаковых ingredients:

- Agave Leaf -> Agave base.
- Apple -> Apple base.
- Banana -> Banana base.
- Corn -> Corn base.
- Honey ingredients -> Honey base.
- Pineapple -> Pineapple base.
- Potato -> Potato base.
- Red Grapes -> Red Grapes base.
- Rice -> Rice base.
- Tomato -> Tomato base.
- Sugar Cane -> Sugar Cane base.
- Wheat -> Wheat base.

Special recipes:

- 6 Wheat + 2 Hop Cones -> Wheat Hop base.
- 4 Juniper Berries + 2 Grapes + Sugar + Wheat -> Juniper base.

## Fermentation

Mash Tub выполняет fermentation.

Особенности:

- Alcoholic fluids имеют несколько стадий fermentation.
- Если оставить подходящую жидкость в процессе слишком долго, она может перейти в vinegar line.
- До fermentation большинство alcohol fluids являются базой/juice/wash, а не готовым напитком.

## Maturation

Barrel выполняет maturation.

Особенности:

- Maturation требует хотя бы одну fermentation stage.
- Maturation меняет drink type/quality для некоторых линий.
- После maturation жидкость обычно уже не идет в обычную distillation.

## Distillation

Distillery выполняет distillation.

Требования:

- Fluid должен быть fermented.
- Fluid не должен быть matured.
- Под Distillery нужен heat source.
- Выход должен быть подключен к Flask или совместимому block entity.

Источники тепла:

- Lava.
- Fire.
- Lit campfire.
- Magma block.

## Примеры линий напитков

- Wheat Hop -> Beer.
- Red Grapes -> Wine, Brandy, Vinegar.
- Apple -> Cider, Apple Brandy.
- Honey -> Mead, Brandy.
- Sugar Cane -> Basi, Rum.
- Juniper -> Gin.
- Agave -> Mezcal, Tequila variants.
- Corn/Wheat/Potato -> Beer/Vodka/Whiskey variants.

## Ethanol

Ethanol получается через purification alcohol fluids в Bunsen Burner.

Использование:

- Chemical ingredient для некоторых tray recipes.
- Горючая жидкость.
- Может добавлять alcohol-related impurity/effects в предметы, если попадает как impurity.
