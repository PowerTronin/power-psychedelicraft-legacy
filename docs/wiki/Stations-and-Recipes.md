# Станции и рецепты

Эта страница описывает основные рабочие блоки мода. Если цепочка не работает, сначала проверь направление входа/выхода, наличие жидкости и то, не теряется ли продукт из-за отсутствующего вывода.

## Обзор станций

| Станция | Назначение | Главный риск |
| --- | --- | --- |
| Стол для сушки | Сушит растения, мак и грибы. | Дождь и слабый свет останавливают прогресс. |
| Деревянный чан | Затирание и брожение. | Нужна вода и правильные ингредиенты. |
| Бочка | Выдержка алкогольных жидкостей. | Не все стадии после выдержки можно перегонять. |
| Колба | Большой буфер жидкости. | Некоторые метки примесей могут не сохраняться в нужной цепочке. |
| Дистиллятор | Перегонка подходящих жидкостей. | Нужен нагрев и подключенный выход. |
| Горелка Бунзена | Реакции, очистка, добавление примесей. | Без верхнего выхода жидкий продукт теряется. |
| Поднос | Затвердевание и кристаллизация жидкостей. | Принимает жидкость только сверху через трубу. |

## Стол для сушки

Рабочие рецепты:

| Вход | Выход |
| --- | --- |
| Коричневый гриб | Коричневые волшебные грибы |
| Красный гриб | Красные волшебные грибы |
| Листья коки | Сушеные листья коки |
| Лист белладонны | Сушеный лист белладонны |
| Лист табака | Сушеный табак |
| Соцветия каннабиса | Сушеные соцветия каннабиса |
| Лист каннабиса | Сушеный лист каннабиса |
| Лист дурмана | Сушеный лист дурмана |
| Пейот | Сушеный пейот |
| Мак | Сушеный мак |

Поведение:

- Слот `0` является выходом.
- Слоты `1-9` являются входами.
- Скорость зависит от света и температуры биома.
- Дождь блокирует сушку, если стол видит небо.
- Зажженная печь, коптильня или плавильная печь рядом может ускорить нагрев.
- Железный стол для сушки работает быстрее обычного.

## Деревянный чан

Чан используется для затирания и брожения.

Свойства:

- Вместимость: 9 ведер.
- Принимает емкости с жидкостью и ингредиенты по ПКМ.
- Может подбирать подходящие предметы рядом.
- Если жидкости нет, оставшиеся ингредиенты можно вернуть.

Примеры затирания:

| Ингредиенты | Основа |
| --- | --- |
| 6 пшеницы + 2 шишки хмеля | Пшенично-хмелевая основа |
| Виноград | Виноградная основа |
| Яблоки | Яблочная основа |
| Медовые ингредиенты | Медовая основа |
| Картофель, кукуруза или пшеница | Соответствующая алкогольная основа |
| 4 ягоды можжевельника + 2 винограда + сахар + пшеница | Можжевеловая основа |
| Лист агавы | Основа агавы |

## Бочка

Бочка нужна для выдержки.

Свойства:

- Вместимость: 8 ведер.
- Работает с алкогольными жидкостями после брожения.
- Имеет варианты из разных пород дерева.

Шаблон рецепта:

```text
 I 
# #
S#S

I = железный слиток
# = подходящие доски
S = палки
```

## Колба

Колба - большой буфер жидкости на 8 ведер.

Полезна после дистиллятора и горелки Бунзена, когда нужно временно хранить продукт или подать его дальше в трубы.

> Для рецептов подноса с важными примесями лучше вести жидкость напрямую из горелки Бунзена через стеклянную трубу. При переносе через колбу часть меток примесей может быть потеряна.

## Дистиллятор

Дистиллятор перегоняет подходящие жидкости.

Источники тепла снизу:

| Источник | Сила нагрева |
| --- | --- |
| Лава | Сильная |
| Огонь или зажженный костер | Средняя |
| Магмовый блок | Слабая |

Для алкогольных жидкостей перегонка работает после брожения и до выдержки. Выход должен быть подключен к колбе или совместимому блоку.

## Горелка Бунзена

Горелка Бунзена используется для реакций и очистки.

Практичная схема:

```text
Стеклянная труба / колба / вход подноса
        ^
        |
 Горелка Бунзена
        |
 Редстоун или источник тепла
```

Правила:

- Обычная стеклянная бутылка работает в малом режиме.
- Модовая бутылка работает в большом режиме и позволяет добавлять твердые ингредиенты.
- Если сверху нет трубы, колбы или подноса, жидкий продукт теряется.
- Если пустая горелка перегрета, она может ломать стекло и наносить урон сущностям рядом.

## Поднос

Поднос кристаллизует или затвердевает жидкость.

Свойства:

- Вместимость: 50 внутренних единиц жидкости.
- Принимает жидкость только сверху через трубу.
- Не наполняется обычным ПКМ.
- После затвердевания результат хранится внутри блока.
- Проще всего забрать результат, сломав поднос.

Основные рецепты:

| Вход | Результат |
| --- | --- |
| Кислота | Таблетка ЛСД |
| Экстракт ипомеи без примеси `lapis_lazuli` | Кристаллический метамфетамин |
| Экстракт ипомеи с примесью `lapis_lazuli` | Синий кристаллический метамфетамин |
| Морфин | Героин |
| Этанол + раствор кокаина | Крэк-кокаин |
| Вода | Сахар |
