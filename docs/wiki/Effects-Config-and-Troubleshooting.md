# Эффекты, конфиг и проблемы

Эта страница нужна для настройки клиента/сервера и диагностики типовых проблем.

## Эффекты веществ

Мод имеет собственную систему drug properties.

Основные типы:

| Тип | Примеры источников |
| --- | --- |
| Алкоголь | Пиво, вино, крепкие напитки, этанол. |
| Каннабис | Косяк, блант, чай, маффин. |
| Табак | Сигареты, сигары. |
| Кокаин | Порошок, жидкий кокаин, крэк. |
| Кофеин | Кофе, кофеин. |
| Сахар | Сахарные рецепты и примеси. |
| Соли для ванн | Жидкость/расходники химической линии. |
| ЛСД/ЛСА | Ипомея, кислота, таблетки/марки. |
| Атропин | Белладонна и дурман. |
| Морфин | Морфин, героин, таблетки. |
| Метамфетамин | Обычный и синий кристаллический метамфетамин. |
| Пейот | Пейот, сок пейота, косяк с пейотом. |
| Грибы | Волшебные грибы. |
| Кава | Сок кавы. |
| Недосып | Ограничения сна и визуальные эффекты. |

Возможные эффекты:

- 2D/3D-шейдеры.
- Сдвиги цвета.
- Волны, пульсации, фракталы.
- Bloom и color bloom.
- Галлюцинируемые сущности.
- Изменения движения и атрибутов.
- Изменения голода и метаболизма.
- Искажения звука и чата.
- Ограничения сна.

## Настройки визуальных эффектов

Если эффекты выглядят странно или клиент нестабилен:

1. Открой настройки Psychedelicraft через Mod Menu, если он установлен.
2. Отключи `Use 2D Shaders`, если падают постэффекты экрана.
3. Отключи `Use 3D Shaders`, если ломается геометрия мира.
4. Отключи совместимость с Iris/Sodium, если используешь эти моды и видишь проблемы с шейдерами.
5. Проверь, что запускается свежий jar форка, собранный после фикса generated assets/data.

## Группы конфига

Точные имена настроек лучше смотреть в generated config после первого запуска.

Основные группы:

| Группа | Что регулирует |
| --- | --- |
| Worldgen | Включение растений и шансы генерации. |
| Balancing | Скорости сушки, брожения, выдержки и обработки. |
| Features | Банки разлома, гармониум, коктейли Молотова. |
| Villagers | Торговля жителей и профессии. |
| Visual | Шейдеры, overlays, motion blur, water/heat distortion. |
| Compatibility | Iris/Sodium shader injections. |

## Типовые проблемы

### Пропали модели, рецепты или игра падает при входе в мир

Симптомы:

- Missing blockstates/models/sounds.
- Краш при входе в мир.
- Рецепты или tags не работают.

Решение в форке: `src/main/generated` теперь закоммичен и попадает в jar. Убедись, что на сервере и клиенте стоит актуальная сборка.

### Горелка Бунзена работает, но жидкость исчезает

Причина: сверху нет колбы, стеклянной трубы или входа подноса.

Решение: подключить выход перед запуском реакции.

### Поднос не наполняется

Причина: поднос принимает жидкость только сверху через стеклянную трубу.

Решение: поставь трубу так, чтобы ее выход смотрел вниз в поднос.

### Синий кристаллический метамфетамин не получается

Причина: примесь `lapis_lazuli` не дошла до подноса.

Решение: веди выход напрямую из горелки Бунзена через стеклянную трубу в поднос, не через колбу.

### Стол для сушки не сушит

Причины:

- Дождь.
- Низкий свет.
- Недостаточно тепла.

Решение: поставить под крышу, добавить свет/тепло или использовать железный стол для сушки.

### Клиент упал с `SIGSEGV` в `libnvidia-glcore`

Это нативный краш OpenGL/NVIDIA-драйвера, а не обычное Java-исключение мода.

Что проверить:

- Запускается ли последняя сборка jar.
- Выключены ли 2D/3D-шейдеры Psychedelicraft для теста.
- Нет ли Iris/Sodium shader injection проблем.
- Повторяется ли краш без постэффектов и motion blur.

## Команды для разработки

Сборка:

```bash
./gradlew clean build
```

Генерация data/assets:

```bash
./gradlew runDatagen
```

Запуск клиента из Gradle:

```bash
./gradlew runClient
```
